# ReflexML narrow novelty / prior-art audit

检索截至 2026-09-28。结论：**否决纯 LR-drop 主线；当前没有已成立的 strong novelty candidate；DO NOT DO LR Terminal Crossover。** 原始 collapse 与因果轨迹之间的关系仍有受限的研究空间，但核心定性结构已有很近的先例。

本轮只读取现有协议、冻结分析报告和原论文；没有修改 ReflexML 代码、重算统计或运行实验。这里采用冻结报告的实验结论，没有重新审计全部生产 artifacts。审计依据包括 [Phase 5 结果](../../RESULTS_PHASE5.md)、[历史轨迹报告](HISTORICAL_DYNAMICS.md)、[LR 轨迹报告](LR_DYNAMICS.md)、[Momentum Reset closure](../../MOMENTUM_RESET_MECHANISM_CLOSURE.md) 与 [m=4 分析](M4_REPORT.md)。

## A. Search coverage

做了 broad discovery、围绕未匹配结构的 targeted search、以“这已经被做过”为假设的 adversarial search，并追查近邻论文的引用。六条工作流分别是 abrupt LR switching、WSD/cooldown、LR×batch/noise、momentum×LR、delayed/disappearing effects、terminal/one-step/remainder batch。

22 篇论文核查了与本问题有关的正文方法、理论或实验章节；这不表示逐页精读全部附录。下表保留 15 篇结构上最近的先例。时间覆盖 2017–2026-09-25；包括 ICML、ICLR、AISTATS、NeurIPS、EMNLP、TMLR 和明确标为 preprint 的 arXiv 工作。检索没有发现把“最后一个不足整批的训练 batch”作为同构处理、解释本文两个配对轨迹末步差异的直接先例；这只能支持 apparently unmatched，不能证明不存在。

另核查了 [Universal Dynamics of WSD](https://arxiv.org/abs/2601.09000) 的 CNN 实验、[Effective Learning Rate Governs Loss Dynamics](https://arxiv.org/abs/2608.24814) 的受控 loss-trajectory matching、[Same Loss, Same Noise, Opposite Schedules](https://arxiv.org/abs/2607.12360) 的条件性 cooldown 理论、[Towards Understanding Momentum Acceleration in River-Valley Loss Landscape](https://arxiv.org/abs/2609.30957) 的 heavy-ball 理论与 LM 实验。它们进一步削弱“快速 LR 响应”“只在 LLM 中已知”“momentum/noise 概念本身新”的定位，但没有直接替代 ReflexML 的特定历史配对结果。其余正文核查是 Mandt et al. (2017)、Smith et al. (2021) implicit regularization 和 Zhu et al. (2024) catapults；未把这些概念强行用于解释本项目。

三个对 novelty 判定重要的边界：

1. **历史与 LR trajectories 不独立。** 令 W 为共同的低-LR Wait/Switch，N 为历史 Now，H 为高-LR Continue，C=W−N，D=H−W。则 C0−Ct=(W0−Wt)+(Nt−N0)，Dt=(Ht−W0)+(W0−Wt)。共同的 W 改善本来就同时进入两者。因此 early alignment 有共享分量，不能单靠形状认定同一机制。
2. **lower LR 不等于 step1 改善。** 冻结 LR 报告的 step1 两臂 validation loss 都变差；低 LR 是变差较少。历史 step1 gap 先扩大，整 epoch closure 才主要由 Wait 改善贡献。不能把这两条 trajectory 讲成同一条单调 rapid-improvement 曲线。
3. **统计与样本范围不同。** h1–4/≈.041 的 endpoint 结论与 36-state A1-only trajectory 不是同一 future-randomness estimand；A1 的 D79≈.04474。轨迹只有十个固定 probes，不能称每步都测量或未来随机性上的普遍响应。m=4 分析报告还披露了 bootstrap matrix materialization 前的一次 endpoint preview；不应声称完全不存在 outcome exposure。

## D. What is definitely not novel

明确否决以下 paper 主线：**“learning-rate drop causes rapid loss improvement。”** P1–4/P6 已给近邻或直接理论/实证；在当前 LR step1 结果上这句话还描述失真。

同样不能主张首次发现：LR switching 会改变轨迹；cooldown 会 sharp loss drop；低 LR 降低噪声/震荡造成的 loss floor；LR×batch/momentum interaction；延迟干预后的 catch-up、history forgetting；短 horizon 与长 horizon 的 intervention value 不同；单步 loss 对 LR 与 batch 敏感。上述现象不需要在完全相同的 Fashion-MNIST MLP 上已发表，才构成 prior art。

精确 state/tape 绑定、frozen paired analysis 和 replay gates 是可信度优势；已有文献没有提供相同 audit 记录，不自动让科学现象变新。

## E. What may still be novel

**Strong candidate：目前没有已成立的候选。** 未匹配完整实验组合，不等于强独立科学贡献；目前证据仍来自一个固定 Fashion-MNIST MLP/SGDM 设置。

**Moderate candidate：一个受控的解释边界案例。** 本文把同一历史 effect 的 horizon dependence、真实 replay 内部时间结构、matched-state LR 因果对照连起来，显示 endpoint LR causality 与全程 temporal explanation 不能互相替代。这比“LR drop 有用”更具体。但 P1/P5 已覆盖主要定性故事，E 又受共享臂限制；目前只能称有潜力的案例整合，不能称已发现新优化机制。

**Weak candidates：** 未匹配的确切 h1–4 pattern、fixed-probe closure 比例、reset 后仍有效、m=4 的具体 attenuation、LR terminal contribution≈31.9% 与历史≈2.84% 的对照。这些是值得报告的结果细节；若缺乏可转移边界，难以独立支撑 paper-level novelty。H 的“absent”必须降格为“点估计小、CI 尚未解析”。

## F. Current best paper-level scientific story

> 在一个固定的延迟 LR 干预中，短期 validation-loss 差距在两臂 LR 统一后消退；精确历史 replay 将 epoch 级突变解析为前段为主的追赶。匹配状态的 LR 反事实确认 LR 对终点差距的作用，但其即时和末端响应与历史 reconvergence 不完全相同。这个受控案例界定了 endpoint 因果作用能够说明什么，以及哪些时间结构仍未被它解释。

这条主线比纯 LR story 更有独立价值，**但目前仍不足以主张新的优化规律**。其中“说明一部分”指证据范围，不是已做 formal mediation 或识别 LR 贡献百分比；形状不同也不证明存在另一种非 LR 机制。论文应正面比较 P1/P5，而不是将 delayed catch-up 作为未被讨论过的现象。

## G. Terminal Crossover decision

**DO NOT DO。** 这是当前研究优先级判断，不是断言它没有任何局部诊断价值。

它会减少的 uncertainty 是：t78→79 的 LR contrast increment，究竟对当下 LR 敏感，还是主要取决于此前 LR 造成的参数/optimizer history，或两者交互。它不能单独识别 remainder batch 的因果作用，也不能把局部 terminal 效应推回历史 closure 主体。

| Possible result | 会新增什么 | 文献关系与对原始 collapse 的价值 |
|---|---|---|
| terminal current-LR effect 强 | 该末步在该两种历史状态下对当前 LR 有局部因果敏感性 | P6 的 checkpoint 单步 LR 响应、P8/P9 finite-step dynamics 已很接近。即使新增末步估计，历史 closure 主体仍在早段，解释贡献有限。 |
| terminal current-LR effect 弱 | 大 terminal increment 不能主要归结为一个简单的 current-LR 主效应；history/path dependence 更值得考虑 | 不能据此说历史 collapse 已解释，也不能证明 momentum 或某个 mechanism；主要重新定位 LR trajectory 的局部异常。 |
| LR-history×current-LR interaction | terminal response 随 treatment-generated state 改变 | optimizer-state transport 与 history-conditioned finite-horizon response 已有 P11/P15 等结构先例。本文 interaction 的方向/幅度会是新估计，通常不是新机制。 |

所以 expected information gain 对“当前 LR 末步还是历史状态”这个局部问题可以有用，**对原始 collapse / 可辩护 paper claim 的预计增量不足以优先继续**。这是定性决策，没有虚构 outcome probabilities 或算数式信息增益。

Opportunity cost：把剩余精力用于约占历史 closure 2.84%、CI 跨零的末步，会延后回答原始 signature 是否可转移。31.9% 与 2.84% 的分母不同，不能把比例之差当正式 interaction 检验。当前最后训练 batch 是 16 个样本、之前通常 128 个；mean reduction 下不能仅因 batch 更小就断言 update 被机械放大。评估仍是同一 full 5,000-example validation，故这不是 evaluation minibatch artifact。中间 snapshots 为 model-only，实施 crossover 还需要严格恢复 optimizer/future identity，不能按“已有快照、只需最后一步”估算成本。

## H. If DO

不适用。本轮没有 crossover 设计或实现。

## I. If DO NOT DO

**唯一更值得做的下一步：对原始 delayed-effect→front-loaded reconvergence signature 做一个预先固定、独立设置的外部复现。**

目的只是检验这个 signature 是否具有超出当前设置的可转移性，以及是否存在相对 P1/P5 的可辩护边界。复现成功也不自动构成 novelty，但它比解析历史上占比小且未解析的末步，更能改变 paper-level 判断。这里只给研究优先级；不选新模型/seed、不提出实验 family，也不授权执行。

## J. Bottom line

ReflexML 仍有受限的独立研究空间，但“LR drop 快速改善”与“延迟后追赶”都已有很近的先例。最可能存活的贡献，是将同一历史 effect 的时间分辨 replay 和严格 LR 反事实联系起来，给出可转移的解释边界；现在还没有证明这个边界可转移。现有末端差异是有趣的描述性残差，尚不是强机制或 strong novelty。当前应停止 Terminal Crossover 优先线，把一次独立复现作为下一步的唯一研究优先项。
